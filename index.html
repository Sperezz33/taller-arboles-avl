BST en un minuto

En cada nodo: todo lo de la izquierda es menor, todo lo de la derecha es mayor. Se inserta bajando desde la raíz (menor → izquierda, mayor → derecha) hasta encontrar un hueco.

Eliminar: tres casos

  1. Hoja: se quita y listo.
  2. Un hijo: el hijo sube a ocupar su lugar.
  3. Dos hijos: se reemplaza por su predecesor = el mayor del subárbol izquierdo. Para encontrarlo: un paso a la izquierda, y luego todo a la derecha hasta que no se pueda más. Ese predecesor se quita de donde estaba (allí siempre es hoja o tiene un solo hijo, a la izquierda).

Medidas del árbol (raíz en nivel 0)

MedidaQué esEjemplo (árbol de abajo)

Si el profe cuenta la altura en nodos (y no en aristas), es la misma más 1. Con raíz = nivel 0, lo normal es contar aristas: una hoja tiene altura 0.

AVL: la receta mecánica

FB (factor de balance) = altura(izquierda) − altura(derecha). Árbol vacío = −1, hoja = 0. Un AVL está bien si todos los nodos tienen FB −1, 0 o +1.

  1. Inserte el número como en un BST normal.
  2. Suba desde el nodo nuevo hacia la raíz recalculando FB. El primer nodo con FB +2 o −2 que encuentre es el pivote (el más profundo desbalanceado). En inserción solo se arregla ese y el resto se arregla solo.
  3. Desde el pivote, mire los dos primeros pasos del camino hacia el nodo nuevo:
    CaminoCasoQué se hace
    izquierda, izquierdaLLUna rotación a la derecha sobre el pivote
    derecha, derechaRRUna rotación a la izquierda sobre el pivote
    izquierda, derechaLRIzquierda sobre el hijo, luego derecha sobre el pivote
    derecha, izquierdaRLDerecha sobre el hijo, luego izquierda sobre el pivote
    Línea recta = 1 rotación. Zig-zag = 2 rotaciones.
  4. Rote y verifique que todos los FB quedaron en −1, 0 o +1.

Los nombres cambian según el profe: a LL algunos le dicen "rotación simple a la derecha" o "II". Lo que importa es la forma.

Regla del medio (el truco para hacerlo a mano sin perderse). Tome los 3 nodos del camino: pivote, hijo y nieto. Ordénelos por valor: a < b < c. El del medio (b) queda arriba, a a su izquierda y c a su derecha. Los subárboles que colgaban de esos tres (máximo 4) se cuelgan de nuevo en orden de izquierda a derecha: T1 y T2 bajo a, T3 y T4 bajo c. Funciona igual para los 4 casos.

Los 4 casos, con el ejemplo más pequeño

Eliminar en AVL

  1. Elimine como en BST (hoja / un hijo / predecesor).
  2. Suba desde el padre del nodo que se quitó físicamente hasta la raíz, revisando FB.
  3. Si un nodo queda en ±2, el hijo que se mira es el del lado más alto (el lado contrario de donde se borró). Si ese hijo tiene FB 0, se trata como línea recta: rotación simple.
  4. No pare después de la primera rotación. En eliminación puede haber más de una: siga subiendo hasta la raíz.

Errores típicos

  • Escoger como pivote la raíz cuando el desbalanceado más profundo está más abajo.
  • En LR o RL hacer solo una rotación.
  • Perder el subárbol del medio (T2 o T3) al rotar: siempre se reubica, nunca desaparece.
  • Usar el sucesor en vez del predecesor.
  • En eliminación, detenerse tras la primera rotación.
  • En la serie: listar mal un término (revise dos veces; un número malo daña todo el árbol).

  1. Subraye el sustantivo (primos, pares, cuadrados…). Esa es la base: tabla 1.
  2. Subraye lo que le hacen (más, menos, el doble, signo alternado…): tabla 2.

# ============================================================
#  ARBOLES BST y AVL en Python (version para estudiar a mano)
#
#  Convenciones (las de su profe):
#    - profundidad de la raiz = 0
#    - altura de una hoja = 0, arbol vacio = -1
#    - eliminar nodo con dos hijos -> PREDECESOR
#      (el mayor del subarbol izquierdo)
#    - FB (factor de balance) = altura(izq) - altura(der)
# ============================================================


class Nodo:
    def __init__(self, valor):
        self.valor = valor
        self.izq = None
        self.der = None
        self.altura = 0          # solo lo usa el AVL


# ======================== BST ========================

def insertar_bst(nodo, valor):
    if nodo is None:
        return Nodo(valor)
    if valor < nodo.valor:
        nodo.izq = insertar_bst(nodo.izq, valor)
    elif valor > nodo.valor:
        nodo.der = insertar_bst(nodo.der, valor)
    return nodo


def buscar(nodo, valor):
    if nodo is None:
        return False
    if valor == nodo.valor:
        return True
    if valor < nodo.valor:
        return buscar(nodo.izq, valor)
    return buscar(nodo.der, valor)


def maximo(nodo):
    # el predecesor de X es maximo(X.izq)
    while nodo.der is not None:
        nodo = nodo.der
    return nodo


def eliminar_bst(nodo, valor):
    if nodo is None:
        return None
    if valor < nodo.valor:
        nodo.izq = eliminar_bst(nodo.izq, valor)
    elif valor > nodo.valor:
        nodo.der = eliminar_bst(nodo.der, valor)
    else:
        # caso 1 y 2: hoja o un solo hijo
        if nodo.izq is None:
            return nodo.der
        if nodo.der is None:
            return nodo.izq
        # caso 3: dos hijos -> predecesor
        pred = maximo(nodo.izq)
        nodo.valor = pred.valor
        nodo.izq = eliminar_bst(nodo.izq, pred.valor)
    return nodo


# ===================== RECORRIDOS =====================

def inorden(nodo, res):
    if nodo is not None:
        inorden(nodo.izq, res)
        res.append(nodo.valor)
        inorden(nodo.der, res)


def preorden(nodo, res):
    if nodo is not None:
        res.append(nodo.valor)
        preorden(nodo.izq, res)
        preorden(nodo.der, res)


def postorden(nodo, res):
    if nodo is not None:
        postorden(nodo.izq, res)
        postorden(nodo.der, res)
        res.append(nodo.valor)


def anchura(raiz):
    # recorrido por niveles (BFS) usando una lista como cola
    res = []
    if raiz is None:
        return res
    cola = [raiz]
    while len(cola) > 0:
        actual = cola.pop(0)
        res.append(actual.valor)
        if actual.izq is not None:
            cola.append(actual.izq)
        if actual.der is not None:
            cola.append(actual.der)
    return res


def altura(nodo):
    if nodo is None:
        return -1
    return 1 + max(altura(nodo.izq), altura(nodo.der))


def profundidad(nodo, valor):
    d = 0
    while nodo is not None:
        if valor == nodo.valor:
            return d
        if valor < nodo.valor:
            nodo = nodo.izq
        else:
            nodo = nodo.der
        d += 1
    return -1                    # no esta


def contar_hojas(nodo):
    if nodo is None:
        return 0
    if nodo.izq is None and nodo.der is None:
        return 1
    return contar_hojas(nodo.izq) + contar_hojas(nodo.der)


# ======================== AVL ========================

def h(nodo):
    if nodo is None:
        return -1
    return nodo.altura


def actualizar(nodo):
    nodo.altura = 1 + max(h(nodo.izq), h(nodo.der))


def fb(nodo):
    return h(nodo.izq) - h(nodo.der)


def rotar_derecha(y):
    x = y.izq
    t2 = x.der
    x.der = y
    y.izq = t2
    actualizar(y)                # primero el que quedo abajo
    actualizar(x)
    return x                     # x es la nueva raiz del subarbol


def rotar_izquierda(x):
    y = x.der
    t2 = y.izq
    y.izq = x
    x.der = t2
    actualizar(x)
    actualizar(y)
    return y


def balancear(nodo):
    actualizar(nodo)
    b = fb(nodo)
    if b > 1:                            # pesa a la izquierda
        if fb(nodo.izq) < 0:             # zig-zag: caso LR
            nodo.izq = rotar_izquierda(nodo.izq)
        return rotar_derecha(nodo)       # caso LL
    if b < -1:                           # pesa a la derecha
        if fb(nodo.der) > 0:             # zig-zag: caso RL
            nodo.der = rotar_derecha(nodo.der)
        return rotar_izquierda(nodo)     # caso RR
    return nodo


def insertar_avl(nodo, valor):
    if nodo is None:
        return Nodo(valor)
    if valor < nodo.valor:
        nodo.izq = insertar_avl(nodo.izq, valor)
    elif valor > nodo.valor:
        nodo.der = insertar_avl(nodo.der, valor)
    else:
        return nodo                      # repetido: no se inserta
    return balancear(nodo)


def eliminar_avl(nodo, valor):
    if nodo is None:
        return None
    if valor < nodo.valor:
        nodo.izq = eliminar_avl(nodo.izq, valor)
    elif valor > nodo.valor:
        nodo.der = eliminar_avl(nodo.der, valor)
    else:
        if nodo.izq is None:
            return nodo.der
        if nodo.der is None:
            return nodo.izq
        pred = maximo(nodo.izq)
        nodo.valor = pred.valor
        nodo.izq = eliminar_avl(nodo.izq, pred.valor)
    return balancear(nodo)


class ArbolAVL:
    def __init__(self):
        self.raiz = None

    def insertar(self, valor):
        self.raiz = insertar_avl(self.raiz, valor)

    def eliminar(self, valor):
        self.raiz = eliminar_avl(self.raiz, valor)


# ============ NODOS CON TUPLAS Y PRIORIDAD ============
# Python compara tuplas campo por campo, de izquierda a derecha:
#   (3, 1, 20) < (3, 2, 5)   -> True  (empatan en 3, decide el 1 < 2)
# Entonces: ponga primero el campo MAS importante.
# Si un campo es "mayor primero", pongale signo menos.

class Evento:
    def __init__(self, prioridad, magnitud, id):
        self.prioridad = prioridad
        self.magnitud = magnitud
        self.id = id

    def clave(self):
        # 1. magnitud (mayor primero)  2. prioridad (menor primero)  3. id
        return (-self.magnitud, self.prioridad, self.id)

    def __lt__(self, otro):
        # con esto "a < b" funciona directo entre eventos
        return self.clave() < otro.clave()

    def __repr__(self):
        return f"#{self.id}(p={self.prioridad}, m={self.magnitud})"


def insertar_evento(nodo, ev):
    if nodo is None:
        return Nodo(ev)
    if ev.clave() < nodo.valor.clave():
        nodo.izq = insertar_evento(nodo.izq, ev)
    else:                                # el id es unico: nunca empatan
        nodo.der = insertar_evento(nodo.der, ev)
    return nodo


# ======================== DIBUJO ========================

def imprimir(nodo, nivel=0):
    # dibuja el arbol de lado: la raiz a la izquierda, la derecha arriba
    if nodo is not None:
        imprimir(nodo.der, nivel + 1)
        print("      " * nivel + str(nodo.valor))
        imprimir(nodo.izq, nivel + 1)

def primos(n):

        for d in range(2, x):
            if x % d == 0:
                es_primo = False
        if es_primo:
            res.append(x)
        x += 1
    return res

Nodos con tuplas y prioridad

Python compara tuplas campo por campo, de izquierda a derecha, y el primer campo distinto decide:

(3, 1, 20) < (3, 2, 5)    # True: empatan en 3, decide 1 < 2 (el 20 y el 5 ni se miran)
(5, 9, 9)  < (6, 0, 0)    # True: decide el primero, 5 < 6
(-5, 1) < (-3, 1)         # True: -5 < -3
  1. Ponga en la tupla primero el campo más importante, luego el segundo, y al final el id (desempate).
  2. Si en un campo "el mayor va primero", póngale signo menos: así el mayor se vuelve el más pequeño.
  3. En el BST, "va primero" = más pequeño = más a la izquierda = sale primero en inorden.
  4. Inserte comparando claves: if ev.clave() < nodo.valor.clave(): va a la izquierda.
class Evento:

        self.prioridad = prioridad
        self.magnitud = magnitud
        self.id = id

    def clave(self):
        # 1° magnitud (mayor primero), 2° prioridad (menor primero), 3° id
        return (-self.magnitud, self.prioridad, self.id)

Calentamiento: ¿a < b?

Árbol 2-3

  • Cada nodo tiene 1 clave y 2 hijos (nodo-2) o 2 claves y 3 hijos (nodo-3).
  • Todas las hojas están en el mismo nivel. Siempre está perfectamente balanceado.
  • Se inserta siempre en una hoja (bajando como en BST: menor que la 1ª clave → hijo izquierdo; entre las dos → hijo del medio; mayor → derecho).
  • Si la hoja queda con 3 claves, se parte: la del medio sube al padre, la menor y la mayor quedan como dos nodos separados.
  • Si el padre también queda con 3, se parte igual (se repite hacia arriba).
  • Si se parte la raíz, la clave del medio es la nueva raíz: el árbol crece hacia arriba, no hacia abajo.

Rojo-Negro

  1. Cada nodo es rojo o negro.
  2. La raíz es negra.
  3. Las hojas nulas (NIL) cuentan como negras.
  4. Un rojo no puede tener hijos rojos.
  5. Desde cualquier nodo, todos los caminos hasta un NIL tienen la misma cantidad de negros.

Insertar

El nuevo entra ROJO. Si el padre es negro, listo. Si el padre es rojo, mire al tío (el hermano del padre):

  • Tío rojo → recolorear: padre y tío a negro, abuelo a rojo. Repita el análisis desde el abuelo.
  • Tío negro y zig-zag → rote sobre el padre para dejarlo en línea recta (y siga al caso de abajo).
  • Tío negro y línea recta → rote sobre el abuelo; el que sube queda negro y el abuelo rojo.
  • Al final, la raíz siempre se pinta negra.
